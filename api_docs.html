POST /endpoints/builder/send/
Session Auth + CSRF

Executes an outbound HTTP request safely with pre-flight SSRF protection, strict timeouts, and response body size limits.

{
  "url": "https://jsonplaceholder.typicode.com/posts/1",
  "method": "GET",
  "headers": {
    "Accept": "application/json"
  },
  "params": {
    "filter": "active"
  },
  "body": "",
  "timeout": 10
}

GET /endpoints/{id}/test/
Login Required

Directly executes a saved endpoint using its stored configuration and decrypted credentials, persisting the result and redirecting to the detailed Test Run report.

Parameters: id (integer) — The primary key of the Endpoint.
GET /testing/suites/{id}/run/
Login Required

Executes all active test cases in the specified Test Suite sequentially, evaluates every assertion rule (status codes, JSON paths, latency thresholds), computes aggregated metrics, and redirects to the TestRun report.

POST /monitoring/{id}/trigger/
CSRF Protected

Manually forces an immediate health check ping for a configured MonitorSchedule, updating uptime metrics and recording an audit log entry.

GET /analytics/reports/run/{id}/csv/
Attachment

Generates and streams a sanitized CSV report containing test scenario outcomes, HTTP codes, latency durations, and failure reasons.

GET /analytics/reports/run/{id}/pdf/
PDF Binary

Renders a professional, audit-ready PDF document with ReportLab, including project summary cards, pass/fail totals, duration tables, and confidentiality notices.
